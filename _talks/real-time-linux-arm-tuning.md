## About this talk

This talk covers techniques for tuning real-time Linux, built on the PREEMPT_RT patch set, for deterministic behavior on ARM-based SoCs. It discusses kernel configuration options, scheduling and interrupt latency considerations, and system-level tuning knobs relevant to embedded ARM platforms. The talk also shares practical measurement approaches for validating real-time performance after applying these tuning steps.
