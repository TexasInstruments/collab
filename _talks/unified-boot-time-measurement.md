## About this talk

This talk presents a unified framework for measuring boot time across the various stages of an embedded Linux boot flow, from initial ROM/bootloader execution through kernel init to userspace readiness. It looks at the challenges of getting precise, repeatable timing data across heterogeneous boot stages and toolchains, and proposes a scalable methodology that can be applied consistently across different platforms. The session is aimed at engineers who need reliable instrumentation to identify and track boot time regressions and optimizations.
