## About this talk

This talk explores how a shared display can be managed across heterogeneous multi-processor systems where Linux serves as the high-level operating system. It discusses coordination between Linux and other processing cores or real-time subsystems that also need to render or contribute content to the same display. The speakers, both from Texas Instruments, share architectural approaches for arbitrating and composing display output across these heterogeneous components. The talk is relevant to engineers working on graphics stacks, display drivers, and multi-core SoC display architectures.
