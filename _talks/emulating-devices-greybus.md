## About this talk

This talk looks at the Greybus subsystem in the Linux kernel and how it can be used to emulate physical devices without requiring the underlying hardware to be present. It covers the Greybus protocol stack, how bundles and modules map onto emulated device nodes, and how this approach can simplify driver development and testing workflows.
