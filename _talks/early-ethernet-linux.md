## About this talk

This talk looks at how to bring up Ethernet connectivity as early as possible in the Linux boot process on embedded systems, rather than waiting until late userspace initialization. It discusses the kernel and driver-level considerations involved in initializing network hardware earlier in boot, and the use cases that benefit from faster network availability, such as network booting or early diagnostics. The session is aimed at engineers working on boot-time optimization and networking subsystems in embedded Linux.
