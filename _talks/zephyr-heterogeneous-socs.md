## About this talk

This talk examines how Zephyr RTOS supports SoCs built from heterogeneous processor cores, such as combinations of Arm Cortex-A, Cortex-M, and DSP cores on the same die. It discusses the build system and configuration mechanisms Zephyr uses to target multiple cores within a single SoC, as well as inter-core communication approaches for coordinating work across processors with different capabilities. The talk also covers considerations around boot flow, memory partitioning, and resource sharing in these multi-core, multi-architecture designs. It offers insight into the practical challenges of running Zephyr in increasingly heterogeneous embedded systems.
