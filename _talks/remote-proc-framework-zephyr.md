## About this talk

This talk introduces the remote processor (remoteproc) framework as implemented in Zephyr RTOS, covering how it handles firmware loading, lifecycle control, and coordination for remote cores in heterogeneous multi-core systems. It discusses how the framework fits into Zephyr's broader driver and subsystem model and how it compares conceptually to remoteproc implementations found in Linux. The talk also addresses practical considerations for developers building multi-core applications that rely on Zephyr's remoteproc support.
