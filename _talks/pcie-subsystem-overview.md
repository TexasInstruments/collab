## About this talk

This talk provides a tour of the Linux kernel's PCI and PCIe subsystem, covering how the kernel enumerates buses, configures devices, and manages resources like BARs and interrupts. It discusses the layered driver model, including host controller drivers, the core PCI framework, and endpoint device drivers, along with how these pieces interact on embedded SoCs. The talk also addresses PCIe-specific topics such as link training, power management states, and MSI/MSI-X interrupt handling. It serves as a foundation for engineers looking to understand or contribute to PCI(e) support in the kernel.
