## About this talk

This talk looks at the challenges of qualifying U-Boot, a bootloader not originally designed with functional safety in mind, for use in automotive systems. It discusses how a structured test framework can be layered onto U-Boot to provide the verification coverage and traceability that automotive safety standards demand. The talk covers test case organization, coverage tracking, and how the framework fits into a broader automotive software safety lifecycle. It aims to help the community understand practical steps toward making U-Boot a viable component in safety-relevant automotive designs.
