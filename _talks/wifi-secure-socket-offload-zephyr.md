## About this talk

This talk introduces WiFi connectivity and secure socket offload capabilities within the Zephyr RTOS. It covers how offloading networking and TLS/socket operations to dedicated hardware or companion chips can reduce load on the main application processor. The speaker discusses the architecture behind integrating offload-capable WiFi modules with Zephyr's networking stack. Attendees can expect insight into the tradeoffs of offload-based networking designs for resource-constrained embedded systems.
