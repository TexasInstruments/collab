## About this talk

This talk explores how the Greybus protocol, originally developed for modular hardware interconnects, can be applied to robotics systems running on Zephyr RTOS. It covers the motivations for using Greybus to link sensors, actuators, and compute modules in a robotic platform, along with the integration work needed to bring Greybus support to Zephyr. The talk is relevant to developers interested in modular, dynamically composable embedded architectures for robotics.
