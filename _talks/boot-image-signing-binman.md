## About this talk

This talk covers efforts to standardize how boot images are generated and cryptographically signed for embedded systems using U-Boot's Binman tool. It discusses the motivation for a common, reusable image-generation and signing flow across different platforms rather than bespoke, per-project scripts. Attendees can expect a look at how Binman fits into secure boot pipelines and the benefits of consolidating this tooling for maintainability and security.
