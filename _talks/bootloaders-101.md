## About this talk

This talk is an introductory walkthrough of how embedded processors start up, from the initial power-on state through the various bootloader stages to a running operating system. It covers concepts such as ROM code, first-stage and second-stage bootloaders, and how control is handed off between them on the way to loading Linux or another OS. The talk is aimed at newcomers, so it favors clear explanations of the overall boot flow over deep implementation detail (exact conference edition inferred from publish date; not independently confirmed).
